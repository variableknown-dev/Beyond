# Beyond

Beyond is a personal AI assistant built to help with everyday questions and tasks through a simple chat interface.

## What Beyond can do

- Answer questions and hold a conversation
- Search the web for recent information and summarize what it finds
- Provide current weather and short forecasts for places around the world
- Tell the current time and date for a timezone or location
- Help with a range of everyday topics in one conversation

Beyond is actively being developed. Answers can be incomplete or incorrect, so verify important information—especially breaking news, weather alerts, and other time-sensitive details—with reliable sources.

## Project status

Beyond is an early-stage project. Some features depend on external services and may be unavailable at times. Historical weather lookup is not currently supported.
